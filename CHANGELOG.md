# CHANGELOG: INTERVIEW COPILOT AI

## [1.0.0] - Initial Release
### Added
- **Core Architecture**: Full-stack Express backend with Vite integration, Electron main/preload IPC scripts, and React 19 UI.
- **Prepopulated Profile**: Senior QA Automation Engineer / QA Lead background (14+ yrs QA, 11+ yrs automation, Selenium WebDriver, Playwright, Java, TypeScript, Cucumber, Maven, Jenkins, SQL).
- **Gemini Engine**: Server-side `@google/genai` orchestration using `gemini-3.8-flash` for text, Q&A, coding, and vision analysis.
- **Live Interview Mode**: Low-latency speech transcription, question detection, and multi-length personalized answers with STAR framework.
- **AI Coding Assistant**: Algorithm and QA automation solver for Java, TypeScript, JavaScript, Python, SQL, C#, and Bash with complexity analysis.
- **Screenshot Analyzer**: Multimodal vision for analyzing code snippets, stack traces, IDE errors, and diagrams from upload or clipboard.
- **Code Workspace**: Monaco editor integration with syntax highlighting, language switching, test case runner, and execution sandbox.
- **Floating Copilot HUD**: Compact overlay mode optimized for placement alongside meeting windows (Teams, Zoom, Google Meet).
- **Practice Mode**: Interactive mock interview simulator with automated evaluation scoring and actionable feedback.
- **Knowledge Library & History**: Curated QA questions library, session history, and Markdown transcript export.
- **Windows Packaging**: Electron Builder configuration with NSIS installer setup for Windows 11.
